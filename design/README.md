# design

The owner's standing decisions about what Propane is: its feel, look, personality and direction. Read
[VISION.md](VISION.md) before designing or changing anything a player sees or feels.

- Everything here is current and binding. It is not a spec, a plan or a changelog: how the game works is in the code,
  the [README](../README.md) and [docs](../docs/); planned work is tracked elsewhere.
- Only the owner changes it. Propose a change with the options laid out neutrally; don't make it.
- When a decision is revoked, change or delete it here in the same commit. Git keeps the history, so nothing stale
  stays.
